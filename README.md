# Dynamic Island для Windows

Лёгкое приложение в стиле Dynamic Island для macOS. Окно полностью скрыто, появляется маленькая пилюля при наведении на верхнюю кромку экрана, а по клику раскрывается панель управления.

## Возможности

- уведомления Windows с временным островком при новых событиях;
- медиаплеер: обложка, трек, перемотка, пауза и переключение треков;
- Wi-Fi, Bluetooth, беззвучный режим, громкость и яркость;
- быстрые вопросы к AI через RouterAI;
- история буфера обмена с быстрой вставкой;
- недавние загрузки: открытие и показ в проводнике;
- погода через OpenWeatherMap;
- кастомизация размеров, сдвига, прозрачности, радиуса и цвета акцента;
- выбор монитора и автозапуск вместе с Windows.

## Требования

- Windows 10 версии 19041 или новее;
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

## Запуск из исходников

```bash
dotnet restore
dotnet run -c Release
```

После запуска наведите курсор на верхнюю кромку экрана и нажмите на пилюлю.

## Публикация

```bash
dotnet publish -c Release -r win-x64 --self-contained false --output publish
```

Готовый запускаемый файл: `publish/DynamicIsland.exe`.

## Настройка API

Ключи вводятся только внутри приложения и хранятся локально с шифрованием Windows DPAPI.

- **OpenWeatherMap** — создайте ключ в [личном кабинете OpenWeatherMap](https://home.openweathermap.org/api_keys) и вставьте его в разделе «Настройки → OpenWeatherMap».
- **RouterAI** — вставьте свой ключ в разделе «Настройки → RouterAI» и нажмите «Сохранить ключ и загрузить модели».

## Структура проекта

- `MainWindow.xaml` и `MainWindow.xaml.cs` — интерфейс, состояния окна, навигация и сценарии взаимодействия;
- `Services/` — уведомления, медиа, системные интерфейсы, буфер обмена, загрузки, погода и AI;
- `Models/` — настройки и модели данных;
- `Converters.cs` — преобразователи значений WPF;
- `App.xaml` — общие стили и ресурсы интерфейса.

## Оптимизация

Приложение использует одно прозрачное окно, статический `HttpClient`, редкие таймеры для фоновых задач, события медиасессий Windows вместо постоянного опроса и ограниченное декодирование обложек. Пилюля показывается только при наведении, полная панель — только по запросу, сетевые запросы выполняются по действиям пользователя и для периодического обновления погоды.

## Конфиденциальность

API-ключи не отправляются никуда, кроме соответствующих API. Настройки и зашифрованные ключи хранятся в каталоге:

```text
%LOCALAPPDATA%\DynamicIsland
```
