# Dynamic Island для Windows

[![Скачать установщик](https://img.shields.io/badge/Скачать-Установщик-8B7CFF?style=for-the-badge)](https://github.com/MyBeautifulMandess/dynamic-island-windows/releases/latest/download/DynamicIsland-Setup.exe)

Dynamic Island в стиле macOS для Windows: управление системой, медиа, уведомления, буфер обмена, загрузки, погода и AI — в одной выдвижной панели.

Окно полностью скрыто. При наведении на верхнюю кромку экрана появляется небольшая пилюля, а по клику раскрывается полный интерфейс.

## Установка

### Способ 1 — установщик

Это рекомендуемый способ.

1. Скачайте [DynamicIsland-Setup.exe](https://github.com/MyBeautifulMandess/dynamic-island-windows/releases/latest/download/DynamicIsland-Setup.exe).
2. Запустите скачанный файл.
3. Следуйте шагам установщика. Права администратора не требуются.
4. После установки оставьте включённым пункт **«Запустить Dynamic Island»**.
5. Наведите курсор на самую верхнюю кромку экрана и нажмите на появившуюся пилюлю.

Ярлык приложения появится в меню «Пуск». Если вы отметили соответствующий пункт при установке, ярлык будет и на рабочем столе.

> Windows может показать предупреждение SmartScreen, потому что установщик не подписан платным сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»**.

### Способ 2 — переносимый файл

Подходит, если не хотите ничего устанавливать.

1. Скачайте [DynamicIsland-Portable.exe](https://github.com/MyBeautifulMandess/dynamic-island-windows/releases/latest/download/DynamicIsland-Portable.exe).
2. Поместите файл в удобную папку.
3. Запустите его двойным щелчком.

Переносимой версии не нужны установка, права администратора или отдельно установленный .NET.

## Первый запуск

1. Если приложение уже запущено, повторный запуск не создаст вторую копию.
2. При первом появлении запроса Windows разрешите приложению доступ к уведомлениям.
3. Откройте пилюлю и перейдите в **«Настройки»**, чтобы по желанию добавить ключи погоды и RouterAI.
4. При необходимости включите **«Запускать вместе с Windows»**.

Ключи вводятся только внутри приложения и хранятся локально с шифрованием Windows DPAPI. Сетевые запросы выполняются только для погоды, погодного обновления и отправленных вами вопросов к AI.

### Настройка API — необязательно

- **OpenWeatherMap** — создайте ключ в [личном кабинете OpenWeatherMap](https://home.openweathermap.org/api_keys) и вставьте его в разделе **«Настройки → OpenWeatherMap»**.
- **RouterAI** — вставьте ключ в разделе **«Настройки → RouterAI»** и нажмите **«Сохранить ключ и загрузить модели»**.

Без этих ключей работают все остальные функции приложения.

## Обновление

Скачайте новый установщик из [последнего релиза](https://github.com/MyBeautifulMandess/dynamic-island-windows/releases/latest) и запустите его поверх установленной версии. Удалять старую версию не нужно. Настройки сохранятся.

## Удаление

Откройте **«Параметры Windows → Приложения → Установленные приложения»**, найдите **Dynamic Island** и выберите **«Удалить»**.

Настройки и зашифрованные ключи остаются в `%LOCALAPPDATA%\DynamicIsland`. Их можно удалить вручную, если приложение больше не понадобится.

## Возможности

- уведомления Windows с временным островком при новых событиях;
- медиаплеер: обложка, трек, перемотка, пауза и переключение треков;
- Wi-Fi, Bluetooth, беззвучный режим, громкость и яркость;
- быстрые вопросы к AI через RouterAI;
- история буфера обмена с быстрой вставкой;
- недавние загрузки: открытие и показ в проводнике;
- погода через OpenWeatherMap;
- настройка размеров, сдвига, прозрачности, радиуса и цвета акцента;
- выбор монитора и автозапуск вместе с Windows.

## Требования

- Windows 10 версии 19041 или новее;
- 64-битная система;
- интернет — только для погоды и AI.

Отдельно устанавливать .NET не нужно: он уже включён в обе сборки.

## Сборка из исходников

Понадобятся [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и, для установщика, [Inno Setup 6](https://jrsoftware.org/isinfo.php).

Запуск из исходников:

```bash
dotnet restore
dotnet run -c Release
```

Сборка переносимой версии:

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true \
  -p:DebugType=None -p:DebugSymbols=false \
  -o dist/portable
```

Сборка установщика:

```bash
ISCC.exe installer/DynamicIsland.iss
```

Готовые файлы появятся в `dist/`.

## Структура проекта

- `MainWindow.xaml` и `MainWindow.xaml.cs` — интерфейс, состояния окна, навигация и сценарии взаимодействия;
- `Services/` — уведомления, медиа, системные интерфейсы, буфер обмена, загрузки, погода и AI;
- `Models/` — настройки и модели данных;
- `Converters.cs` — преобразователи значений WPF;
- `App.xaml` — общие стили и ресурсы интерфейса;
- `installer/DynamicIsland.iss` — конфигурация установщика Inno Setup.

## Оптимизация

Приложение использует одно прозрачное окно, статический `HttpClient`, редкие таймеры для фоновых задач, события медиасессий Windows вместо постоянного опроса и ограниченное декодирование обложек. Пилюля показывается только при наведении, полная панель — только по запросу.

## Отчёт по нагрузке

Замеры выполнены на опубликованной сборке на Windows с 20 логическими процессорами и 15,7 ГБ ОЗУ.

| Состояние | CPU от всей системы | Рабочая память | Private memory |
|---|---:|---:|---:|
| Полностью скрыто | 0,12% | 332,6 МБ | 263,3 МБ |
| Пилюля при наведении | 0,12% | 334,1 МБ | 264,8 МБ |
| Открытая панель | 0,09–0,13% | 333,5 МБ | 265,6 МБ |
| Открытый плеер | 0,13% | 333,6 МБ | 265,9 МБ |

- В пересчёте на одно ядро процессорная нагрузка составляет **1,8–2,6%**.
- В состоянии покоя: **25–26 потоков**, **957–969 дескрипторов**, **0,3 МБ** файла подкачки, **0 КБ/с** дискового ввода-вывода и **0%** GPU.
- 12 последовательных циклов «скрыто → пилюля → раскрыть → скрыть» увеличили память менее чем на 1 МБ, после чего она стабилизировалась. Накопления потоков и дескрипторов не обнаружено.
- Основной расход — около **333 МБ** оперативной памяти, что ожидаемо для WPF-приложения с WinRT API, медиа и прозрачным окном.

## Конфиденциальность

API-ключи не отправляются никуда, кроме соответствующих API. Настройки и зашифрованные ключи хранятся в каталоге:

```text
%LOCALAPPDATA%\DynamicIsland
```
